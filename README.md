# CLI

Proyecto de practica para aprender Git, GitHub CLI (gh) e Integracion Continua (CI).

## Objetivo

Recorrer paso a paso el flujo de trabajo de un proyecto real:

1. Commits en Git.
2. Repositorio remoto en GitHub.
3. Pipeline de CI con GitHub Actions (tests + lint).
4. Pull requests y proteccion de rama.

## Comandos

- Tests: `pytest -q`
- Lint: `ruff check .`

## Stack

- Python 3.13
- pytest (tests)
- ruff (lint)
